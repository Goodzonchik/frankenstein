# Naming conventions

## Общие правила

1. Для именования функций и методов применяем трехступенчатую модель Фейтельсона


## Примеры

### Функции именуются по принципу - первое слово это действие

**Функции мапперы**

Функции мапперы именуются по принципу `map`**X**`to`**Y**, где **X** - изначальный тип, а **Y** - конечный тип.

```ts
  mapUsersDtoToUser(usersDto: UserDto) User[]
```

Файл с функцией называется аналогично, но в kebab-case

```
  map-user-dto-to-user.ts
```
